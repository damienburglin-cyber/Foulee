# Foulée

Pilotage Bluetooth d'un tapis de course (protocoles FitShow et FTMS) : vitesse et inclinaison, programmes, historique et bilan des séances.

Page en ligne : https://damienburglin-cyber.github.io/Foulee/ — à ouvrir dans Chrome (Android ou ordinateur), le Bluetooth web demande une adresse en HTTPS.

Les séances, programmes et réglages restent dans le navigateur (stockage local) ; rien n'est envoyé ailleurs. Export / import dans Réglages.
